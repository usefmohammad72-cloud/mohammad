# Agent Task Board

Use one section per task.

## Status values

`BACKLOG` · `PLANNED` · `IN PROGRESS` · `BLOCKED` · `REVIEW` · `DONE`

## Template

```text
### TASK-XXXX — Title
Status: BACKLOG
Owner: Orchestrator / Claude / Codex / Research / Design / Vision / QA / Docs

Goal:

Inputs:

Acceptance criteria:

Dependencies:

Artifacts:

Tests / QA:

Notes:
```

## Rules

- Keep task descriptions short and executable.
- Link important artifacts or commits.
- Do not paste secrets into the task board.
